## Goal

Delete all v1 pushback surface. After this story, `grep -rn '@/lib/push-back\|/api/push-back\|PushBackModal' src/ --include='*.ts' --include='*.tsx'` returns **zero hits**.

The story is mechanical. No new code, no new tests. The only "test" is that `pnpm typecheck && pnpm lint && pnpm test && pnpm build` all pass after the deletions — which proves there were no orphan importers we missed.

This is doc text, not an import — leaving it preserves the rationale paper trail and falls outside this story's grep audit scope (which targets imports and runtime references, not commentary).
