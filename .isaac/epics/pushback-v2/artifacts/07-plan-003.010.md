## Detailed change plan

### 1. `<ChatInterface>` disclosure text

**Old (current source, line 228):**

```
what you type is sent to anthropic to generate a reply, and kept on this site for 90 days so maria can see how the chat is used. no ip, no account — just the conversation.
```

**New (locked draft from PRD §"Privacy disclosure update text"):**

```
what you type is sent to anthropic to generate a reply, and kept on this site for 90 days so maria can see how the chat is used. when you've come from a fieldwork piece, parts of substantive arguments may surface as anonymous quotes on that piece. no ip, no account — just the conversation.
```

British English, lowercase, voice-continuous with the existing tone. Single text replacement; no other component changes.

### 2. `<ChatInterface>` test updates

```tsx
// In the "renders the privacy note reflecting the 90-day retention window" test:
expect(screen.getByText(/sent to anthropic/i)).toBeInTheDocument();
expect(screen.getByText(/kept on this site for 90 days/i)).toBeInTheDocument();
expect(screen.getByText(/no ip, no account/i)).toBeInTheDocument();
// NEW: public-quoting clause.
expect(screen.getByText(/anonymous quotes on that piece/i)).toBeInTheDocument();
```

Plus a new test asserting the OLD disclosure shape is NOT present:

```tsx
it('does NOT render the pre-v2 disclosure shape (old text removed)', () => {
  render(<ChatInterface />);
  // The pre-v2 text ended with "no ip, no account — just the conversation."
  // immediately after "...how the chat is used." with no public-quoting
  // clause between. Grep guard.
  const text = document.body.textContent ?? '';
  // The current text contains both fragments; the assertion checks the new
  // clause sits between them.
  const usedIdx = text.indexOf('how the chat is used.');
  const ipIdx = text.indexOf('no ip, no account');
  const anonIdx = text.indexOf('anonymous quotes on that piece');
  expect(usedIdx).toBeGreaterThan(-1);
  expect(ipIdx).toBeGreaterThan(-1);
  expect(anonIdx).toBeGreaterThan(usedIdx);
  expect(anonIdx).toBeLessThan(ipIdx);
});
```

### 3. `/privacy` page extension

Insert a new paragraph in the `/argue conversations` section explaining public quoting. Placement: between the existing "What is stored…" paragraph and "After 90 days…" paragraph (logical flow: what we collect → what we surface publicly → retention).

```tsx
<p>
  When a conversation arrives via the <strong>[ argue with this ]</strong> link on a
```
