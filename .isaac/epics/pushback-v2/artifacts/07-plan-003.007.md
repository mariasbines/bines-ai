# Plan — Story 003.007: <PushbackSummary> + build-time enrichment + count badge

**Epic:** `pushback-v2`
**Phase:** 7 (Plan)
**Story:** 003.007
**Tier:** 🔴 Full TDD

---

## Goal

Bring the silent argue-judges corpus to the public site. Three deliverables, single coherent build-time data flow:

1. **Build-time enrichment** — `getFieldworkBySlug` (and `getAllFieldwork`) call `getJudgesForSlug` and merge a top-level `pushback: PushbackEnrichment` into every `Fieldwork`. Loader-authoritative; frontmatter `pushback.count` is forward-compat detritus.
2. **`<PushbackSummary>` server component** — rendered between `<MdxBody>` and `<FieldworkArticleFooter>` on each piece. Returns `null` on count=0. Plain React text nodes (no `dangerouslySetInnerHTML`). Component-level truncation at `EXCERPT_MAX_CHARS` as belt-and-braces.
3. **Count badge on `<FieldworkCard>`** — small accent-tinted pill next to the existing "in rotation" / status pill. "1 pushback" / "n pushbacks". Absent silently when count=0.

## Approach (high level)

The data flow is the spine. Everything else is rendering against a stable shape.

```
   content/fieldwork/*.mdx
            │
            ▼  readMdxFile + Zod validation (existing)
       piece (Fieldwork without `pushback` field)
            │
            ▼  getJudgesForSlug(slug)  ← from src/lib/argue-judge/loader.ts (003.003, shipped)
       PushbackEnrichment | null
            │
            ▼  merge — null caught and replaced with empty shape
       Fieldwork & { pushback: PushbackEnrichment }
            │
            ├──────► /fieldwork (FieldworkCard with badge)
            └──────► /fieldwork/[slug] (FieldworkArticle with PushbackSummary)
```

The `.catch()` on the enrichment call is non-negotiable: build must never fail because the Blob store is unreachable or empty. Empty corpus = empty enrichment = silent zero-count = no rendered summary, no badge. Architecturally fail-safe (PB2-OPS-004).

### 2. Loader change — `src/lib/content/fieldwork.ts`

Extend `getAllFieldwork` to enrich each piece, not `getFieldworkBySlug` directly — keeps the data flow single-source (`getFieldworkBySlug` and `getFieldworkByStatus` both go through `getAllFieldwork`):

```ts
import { getJudgesForSlug, type PushbackEnrichment } from '@/lib/argue-judge/loader';

const EMPTY_ENRICHMENT: PushbackEnrichment = { count: 0, landed: 0, excerpts: [] };

export async function getAllFieldwork(options: LoaderOptions = {}): Promise<Fieldwork[]> {
  const { fieldworkDir } = contentPaths(options.contentRoot ?? DEFAULT_CONTENT_ROOT);
  const files = await listMdxFiles(fieldworkDir);

  const pieces = await Promise.all(
    files.map((f) => readMdxFile(f, FIELDWORK_FRONTMATTER)),
  );

  // Enrich each piece with judge-derived pushback summary. .catch() makes
  // enrichment failures non-fatal: build completes with empty enrichment.
  // (PB2-OPS-004 fail-safe.)
  const enriched: Fieldwork[] = await Promise.all(
    pieces.map(async (p) => {
      const enrichment = await getJudgesForSlug(p.frontmatter.slug).catch(
        (err: unknown) => {
          console.error(
            '[fieldwork] judge enrichment failed for',
            p.frontmatter.slug,
            '—',
            err instanceof Error ? err.name : 'unknown',
          );
          return null;
        },
      );
      return { ...p, pushback: enrichment ?? EMPTY_ENRICHMENT };
    }),
  );

  const filtered = options.status
    ? enriched.filter((p) => p.frontmatter.status === options.status)
    : enriched;

  return filtered.sort((a, b) =>
    b.frontmatter.published.localeCompare(a.frontmatter.published),
  );
}
```

Note: `getJudgesForSlug` already returns null on its own internal errors (logs the error name). The `.catch()` here is a second defence: covers the case where loader itself throws (e.g. a future bug or a module-load error).

### 3. `<PushbackSummary>` component

```tsx
// src/components/PushbackSummary.tsx
import { EXCERPT_MAX_CHARS } from '@/lib/argue-judge/schema';

interface PushbackSummaryProps {
  count: number;
  landed: number;
  excerpts: string[];
}

/**
 * Truncate at the last whitespace before cap, append " — ". Belt-and-braces
 * atop the schema-level cap (both = 240 via EXCERPT_MAX_CHARS). The runner +
 * schema already enforce ≤240; this guards against a hypothetical schema
 * bypass or a future relaxation of the schema cap.
 */
function truncateExcerpt(text: string): string {
  if (text.length <= EXCERPT_MAX_CHARS) return text;
  const slice = text.slice(0, EXCERPT_MAX_CHARS);
  const lastSpace = slice.lastIndexOf(' ');
  // If there's no whitespace within the slice, fall back to a hard cut at
  // the cap. (Very unlikely for natural-language excerpts.)
  const cut = lastSpace > 0 ? slice.slice(0, lastSpace) : slice;
  return `${cut} — `;
}

/**
 * Public summary of judge verdicts on a Fieldwork piece. Renders nothing
 * when count is zero. All visitor text is rendered as React text nodes —
 * never via dangerouslySetInnerHTML (PB2-SEC-004).
 */
export function PushbackSummary({ count, landed, excerpts }: PushbackSummaryProps) {
  if (count === 0) return null;

  return (
    <section
      aria-label="Pushback summary"
      className="mt-12 pt-6 border-t border-ink/15"
    >
      <p className="font-mono text-xs uppercase tracking-[0.14em] text-ink/60">
        pushback ({count})
      </p>
      {landed > 0 ? (
        <p className="font-mono text-xs uppercase tracking-[0.14em] text-ink/60 mt-1">
          landed ({landed})
        </p>
      ) : null}
      <div className="mt-6 space-y-5">
        {excerpts.map((raw, i) => {
          const text = truncateExcerpt(raw);
          return (
            <blockquote
              key={i}
              className="font-serif italic text-lg text-ink/80 border-l-2 border-accent pl-4"
            >
              <p>{text}</p>
              <cite className="not-italic font-mono text-xs uppercase tracking-[0.14em] text-ink/50 block mt-2">
                — anonymous
              </cite>
            </blockquote>
          );
        })}
      </div>
    </section>
  );
}
```

**Voice-check anchor labels:** `pushback`, `landed`, `anonymous`. Lowercase, mono, editorial register. Maria sign-off captured in commit message.

Note: server component (no `'use client'`). The component file deliberately does **NOT** import React explicitly — Next.js / React 19 auto-imports work for JSX. (Mirrors `<FieldworkArticleFooter>`.)
