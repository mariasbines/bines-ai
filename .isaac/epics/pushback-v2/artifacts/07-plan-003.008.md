# Plan — Story 003.008: [ argue with this ] CTA on FieldworkCardCtas

**Epic:** `pushback-v2`
**Phase:** 7 (Plan)
**Story:** 003.008
**Tier:** 🟢 Smoke Tests

---

## Goal

Replace the hidden `[ push back ]` element in `<FieldworkCardCtas>` with a visible `<Link href="/argue?from=<slug>">[ argue with this ]</Link>`. The CTA must:

- Appear on **every** Fieldwork index card, regardless of whether the piece has a testimonial or any pushbacks yet.
- Use the same visual register as the existing `[ watch ]` CTA — lowercase, square brackets, font-mono, border, hover/focus styles.
- Use the existing `motion-reduce:transition-none` class for accessibility.

## Approach

`<FieldworkCardCtas>` currently has an early-return at `if (!hasTestimonial) return null;` — that gates the entire CTA row on the existence of a testimonial. With this story, the CTA row becomes mandatory (every card has at least the `[ argue with this ]` link), so the early-return must be removed.

The component is a `'use client'` island because of `<WatchDialog>` state. The CTA itself is just an anchor — it doesn't need client-side state — but it lives inside this client component, which is fine (a `<Link>` in a client component is no different from one in a server component for routing).

## Files

## Detailed change plan

### `FieldworkCardCtas.tsx`

```tsx
'use client';

import { useState } from 'react';
import Link from 'next/link';
import { WatchDialog } from './WatchDialog';
import type { Fieldwork } from '@/lib/content/types';

interface FieldworkCardCtasProps {
  piece: Fieldwork;
}

/**
 * Client island inside <FieldworkCard> — manages [ watch ] modal state.
 * Keeps the card body itself server-rendered.
 *
 * The card title remains the primary affordance into the detail page;
 * `[ argue with this ]` opens the Argue chat with `?from=<slug>` so the
 * piece is captured by the chat-route preface (story 003.002) and the
 * resulting judge verdict is attributed back to this piece (story
 * 003.003 onward).
 */
export function FieldworkCardCtas({ piece }: FieldworkCardCtasProps) {
  const [watchOpen, setWatchOpen] = useState(false);
  const { media, title, slug } = piece.frontmatter;
  const hasTestimonial = !!(media.testimonial && media.posterFrame);

  return (
    <>
      <div className="font-mono text-xs uppercase tracking-[0.14em] flex flex-wrap gap-3">
        <Link
          href={`/argue?from=${slug}`}
          className="border px-3 py-1.5 border-ink/20 text-ink/80 hover:text-accent hover:border-accent transition-colors motion-reduce:transition-none"
        >
          [ argue with this ]
        </Link>
        {hasTestimonial ? (
          <button
            type="button"
            data-fieldwork-cta="watch"
            onClick={() => setWatchOpen(true)}
            className="border px-3 py-1.5 border-ink/20 text-ink/80 hover:text-accent hover:border-accent transition-colors motion-reduce:transition-none"
            aria-label="Watch video testimonial"
          >
            [ watch ]
          </button>
        ) : null}
      </div>
      {hasTestimonial ? (
        <WatchDialog
          open={watchOpen}
          onClose={() => setWatchOpen(false)}
          src={media.testimonial!}
          poster={media.posterFrame!}
          captions={media.testimonialCaptions}
          title={`Watch: ${title}`}
        />
      ) : null}
    </>
  );
}
```

Key changes:
1. Removed the `if (!hasTestimonial) return null;` early-return.
2. Added `slug` to the frontmatter destructure.
3. Added the `<Link>` as the first child of the CTA row.
4. The `<WatchDialog>` and `[ watch ]` button are now conditionally rendered inside the row.
5. Stripped the now-stale comment about the hidden `[ push back ]`.

Note on story scope: the story description AC-001 says "before `[ read ]`" — the codebase has already retired `[ read ]` (memory `project_morgan_admin_home_redesign.md` is from 26 Apr; this card-CTA changeover happened on the bines.ai side as part of an earlier refinement, see `<FieldworkCardCtas>` source comments). The current order is just `[ watch ]`. The new `[ argue with this ]` ships **before** `[ watch ]` to keep it as the consistent leftmost CTA across all cards (every card has it; only some have `[ watch ]`). This is a defensible deviation from the story's literal wording and matches the spirit of the story (the CTA is universal; `[ watch ]` is contextual).
