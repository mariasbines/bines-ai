# Story 005.003: Gallery components + `/gallery` page route

## Description

Build the gallery itself. Three new files: `src/app/gallery/page.tsx` (server component shell), `src/components/Gallery.tsx` (client; scroll container, keyboard nav, scroll affordance), `src/components/GalleryPanel.tsx` (client; per-piece panel with accent threading, caption + scrim, click-through link). Renders the 7 scoped Fieldwork pieces as horizontal scroll-snap full-viewport panels. Covers most user-facing ACs.

This is the user-experience story of the epic — the visual + interaction work.

## Technical Tasks

1. **Create `src/app/gallery/page.tsx`** — server component:
   - Export `metadata` object (title, description, openGraph)
   - Default export async function `GalleryPage`: `const pieces = await getGalleryFieldwork(); return <Gallery pieces={pieces} />` wrapped in page-header markup (`<h1>` + intro `<p>`)
2. **Create `src/components/Gallery.tsx`** — client component:
   - `'use client'` directive
   - Props: `{ pieces: Fieldwork[] }`
   - Outer `<section role="region" aria-label="Fieldwork gallery, horizontal scroll">` with `tabIndex={0}` and ref
   - CSS classes for `overflow-x-auto` + `flex` + `scroll-snap-type: x mandatory`
   - `useEffect` registering a `keydown` listener on the container ref; on `ArrowLeft` / `ArrowRight` calls `preventDefault()` then `container.scrollBy({ left: ±innerWidth, behavior: 'smooth' })`; cleanup on unmount
   - Renders `pieces.map((piece, i) => <GalleryPanel key={piece.frontmatter.slug} piece={piece} priority={i === 0} />)`
   - Renders the `← →` affordance glyph absolutely positioned top-right of the container (font-mono, low contrast: `text-ink/30`)
3. **Create `src/components/GalleryPanel.tsx`** — client component:
   - `'use client'` directive
   - Props: `{ piece: Fieldwork; priority: boolean }`
   - Defensive guard: `if (!piece.frontmatter.media.headerVideo || !piece.frontmatter.media.posterFrame) { console.warn(...); return null; }`
   - Outer `<article>` with `scroll-snap-align: center`, `w-screen h-[100dvh]`, `relative` positioning, accent style: `style={{ ['--color-accent' as string]: accentVar(accentFor(piece)) }}`
   - Wraps content in `<Link href={`/fieldwork/${slug}`}>` with `focus-visible:ring-2 focus-visible:ring-accent`
   - Renders `<VideoLoop src={media.headerVideo!} poster={media.posterFrame!} alt={`Atmospheric loop for ${title}`} priority={priority} pauseWhenOffscreen={true} className="absolute inset-0" />`
   - Renders scrim: `<div className="absolute inset-x-0 bottom-0 h-1/3 bg-gradient-to-t from-ink/70 to-transparent pointer-events-none" />`
   - Renders caption: `<div className="absolute bottom-6 left-6 font-mono text-xs uppercase tracking-[0.14em]"><span className="text-accent">fieldwork {idPadded}</span> · <span className="text-paper">{title}</span></div>`
   - Renders first-panel right-edge gradient when `priority === true`: `<div className="absolute inset-y-0 right-0 w-16 bg-gradient-to-l from-ink/10 to-transparent pointer-events-none" />`
4. **Tests:**
   - `src/components/__tests__/Gallery.test.tsx`: renders N panels for N pieces; arrow-key listener scrolls by panel width; affordance glyph present; cleanup on unmount removes listener.
   - `src/components/__tests__/GalleryPanel.test.tsx`: renders video + caption; `--color-accent` CSS var set; click-through link href correct; defensive return-null + console.warn when media missing; scrim element present; first-panel right-edge gradient only when `priority === true`.
   - Mock `<VideoLoop>` in component tests (per existing pattern in `FieldworkArticle.test.tsx`) to avoid jsdom video API issues.
5. **Run all four quality gates locally** before opening PR.

## Notes

- The first-panel-only right-edge gradient is a small chrome detail but important for non-touch desktop UX. Render it conditionally based on `priority` (priority is `true` only for index 0).
- The scrim gradient direction: `bg-gradient-to-t` (from bottom up). Use `from-ink/70 to-transparent` for warm-ink scrim; tune the opacity in manual testing if needed.
- The `← →` affordance glyph: literal "←" and "→" characters separated by a thin space. Position `absolute top-6 right-6`, `text-ink/30`. Should be quiet — visitor barely notices it but finds it when looking for a hint.
- Test mock for `<VideoLoop>`: existing pattern in `FieldworkArticle.test.tsx` mocks the module with `vi.mock('./VideoLoop', () => ({ VideoLoop: () => <div data-testid="mock-video-loop" /> }))`. Reuse this approach to keep tests deterministic.
- The page route's `<h1>` and intro `<p>` should be inside a container with constrained width (`max-w-3xl mx-auto px-4`) and adequate top padding — sits above the full-viewport gallery section. The gallery section itself escapes the container with `w-screen relative left-1/2 -translate-x-1/2` (or similar full-bleed pattern) so it can occupy the entire viewport width.
