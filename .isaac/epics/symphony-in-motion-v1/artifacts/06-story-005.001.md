# Story 005.001: Content loader foundation — status union + gallery helper

## Description

Extend `getAllFieldwork` in `src/lib/content/fieldwork.ts` to accept an array of statuses in addition to a single status. Add a `GALLERY_SCOPE` constant and a `getGalleryFieldwork()` helper that returns the gallery-scope pieces (`in-rotation` + `changed-my-mind`) in descending `published` order. Add tests for the array branch, the gallery helper, and an explicit FW05-exclusion guard.

Pure data-layer work — no UI changes. Foundation for stories 005.003 and the FW05 guard required by PRD AC-003.

## Acceptance Criteria

- [ ] **AC-001.1** — `getAllFieldwork({ status: 'in-rotation' })` continues to return in-rotation pieces only, in descending `published` order. Existing test cases unchanged and passing.
- [ ] **AC-001.2** — `getAllFieldwork({ status: ['in-rotation', 'changed-my-mind'] })` returns the union of both status types, in descending `published` order. (Maps to PRD AC-020.)
- [ ] **AC-001.3** — `getAllFieldwork({ status: ['in-rotation'] })` (single-element array) returns same result as `getAllFieldwork({ status: 'in-rotation' })`.
- [ ] **AC-001.4** — `getAllFieldwork()` (no status) returns all pieces regardless of status.
- [ ] **AC-001.5** — `getGalleryFieldwork()` returns exactly the union of `in-rotation` + `changed-my-mind` pieces, sorted descending by `published`. (Maps to PRD AC-021.)
- [ ] **AC-001.6** — `getGalleryFieldwork()` does NOT include FW05 (`retired-evolved`), nor any other retired piece. Explicit test fixture or filesystem-loaded test verifies this. (Maps to PRD AC-003.)
- [ ] **AC-001.7** — `GALLERY_SCOPE` is exported as `readonly FieldworkStatus[]` = `['in-rotation', 'changed-my-mind']` for downstream consumers.
- [ ] **AC-001.8** — TypeScript: `LoaderOptions.status` widens to `FieldworkStatus | readonly FieldworkStatus[]`; all existing callers compile without modification.
- [ ] **AC-001.9** — Quality gates: `pnpm typecheck && pnpm lint && pnpm test && pnpm build` all green.

## Technical Tasks

1. **Widen `LoaderOptions.status`** in `src/lib/content/fieldwork.ts` to `FieldworkStatus | readonly FieldworkStatus[]`.
2. **Normalise input in filter logic.** Build a `wanted: Set<FieldworkStatus>` from the input (string → single-element set; array → set). Apply `.filter(p => wanted.has(p.frontmatter.status))`. Skip filtering entirely if `status` is undefined.
3. **Add `GALLERY_SCOPE` constant** at module top: `export const GALLERY_SCOPE: readonly FieldworkStatus[] = ['in-rotation', 'changed-my-mind'] as const;`
4. **Add `getGalleryFieldwork()` helper:** thin wrapper that calls `getAllFieldwork({ status: GALLERY_SCOPE, contentRoot: options.contentRoot })`. Type signature: `(options?: Omit<LoaderOptions, 'status'>) => Promise<Fieldwork[]>`.
5. **Tests in `src/lib/content/__tests__/fieldwork.test.ts`:**
   - Add test "accepts array of statuses and returns union"
   - Add test "single-element array status === single-string status"
   - Add test "getGalleryFieldwork returns in-rotation + changed-my-mind only"
   - Add test "getGalleryFieldwork excludes retired-evolved (FW05 guard)"
   - Verify existing tests untouched and passing
6. **Run all four quality gates locally** before opening PR.
